# gaussian-dag tutorials

A five-part walkthrough of the library, from a first MI evaluation to a
multi-layer Gaussian network with shared-budget joint optimisation.

| # | Topic | File |
| --- | --- | --- |
| 1 | Installation and your first MI evaluation | [`tutorial-1-installation-and-first-mi.md`](tutorial-1-installation-and-first-mi.md) |
| 2 | Building a DAG and reading K-blocks (diamond) | [`tutorial-2-building-a-dag.md`](tutorial-2-building-a-dag.md) |
| 3 | PGA optimisation with constraints | [`tutorial-3-pga-with-constraints.md`](tutorial-3-pga-with-constraints.md) |
| 4 | Parameter sharing (relay broadcast) | [`tutorial-4-parameter-sharing.md`](tutorial-4-parameter-sharing.md) |
| 5 | Reproducing Fig. 5 of the paper | [`tutorial-5-reproducing-fig5.md`](tutorial-5-reproducing-fig5.md) |

Each tutorial is self-contained and includes runnable code snippets. The
examples under `../examples/` accompany Tutorials 2–5 as ready-to-run
scripts.
